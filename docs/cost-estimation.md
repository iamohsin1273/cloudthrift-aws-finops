# Cost assumptions

Illustrative baseline, not a quote: 30 days, one Cost Explorer page per day, no retries: 30 × $0.01 = **$0.30/month** for Cost Explorer API. Pagination and retries add $0.01 per request. AWS documents [Cost Explorer API pricing](https://aws.amazon.com/aws-cost-management/aws-cost-explorer/pricing/) and [pagination charges and delayed availability](https://docs.aws.amazon.com/cost-management/latest/userguide/ce-what-is.html). Enabling Cost Explorer is a separate account decision and cannot be undone according to AWS documentation.

Scheduler: 30 invocations is within its published 14 million monthly free tier if available and not consumed by other usage; see [EventBridge pricing](https://aws.amazon.com/eventbridge/pricing/). Lambda, S3 storage/requests/versions, CloudWatch Logs and any data transfer may incur additional charges depending on region, volume and shared free-tier eligibility. Their total is unknown without actual usage; state storage also incurs S3 costs. Existing AWS resources remain billable. Use the AWS Pricing Calculator and current regional prices before deployment. This project does not create a budget and no budget prevents charges.
